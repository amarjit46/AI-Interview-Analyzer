# AI Interview Analyzer

An AI-powered application that analyzes spoken interview answers and provides objective feedback on communication skills using Machine Learning and NLP.

## Planned Features

* Speech-to-text transcription
* Filler word detection
* Speaking speed analysis (WPM)
* Keyword relevance scoring
* Sentiment analysis
* Interactive Streamlit dashboard
* Downloadable interview feedback report

## Tech Stack

* Python
* NumPy & Pandas
* Scikit-learn
* Whisper
* Streamlit
* Plotly
